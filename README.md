# 작은 이야기 공방

아이의 그림·사진·짧은 동영상과 놀이 기록으로 교사가 동화책을 만드는 **1차 프로토타입**입니다. 교사 1명·상상반 1개·가상 어린이 별이 1명의 로컬 단일 사용자 모드로 동작합니다. 실제 AI API 키 없이 전체 제작 흐름을 체험할 수 있습니다.

**설치 없이 체험하려면:** [GitHub Pages 설정 안내](docs/try-online.md)를 따라 저장소 설정에서 Pages를 켜세요. 준비된 파일을 그대로 배포할 수 있고 개인 컴퓨터에 Node.js를 설치할 필요가 없습니다. 활성화 전에는 인터넷 접속 주소가 동작하지 않습니다.

## 실행하기

1. [Node.js](https://nodejs.org/) 22 이상을 설치합니다.
2. 이 저장소를 내려받아 터미널에서 저장소 폴더로 이동합니다.
3. 아래 명령을 차례로 실행합니다.

```sh
npm ci
npm start
```

브라우저에서 `http://localhost:3000`에 접속합니다. 서버를 종료하려면 터미널에서 Ctrl+C를 누릅니다. 실행 자체에는 외부 패키지가 필요하지 않고, `npm ci`는 개발 테스트 도구를 설치합니다.

## 이야기 책장과 함께 나누기

홈에는 이야기 책장, 함께 나누기, 창작 공방의 세 가지 진입 메뉴가 있습니다. 책장에서는 제목·작가·본문 검색, 주제 선택, 최근 순/가나다순 정렬, 내가 만든 책/샘플 책 구분이 가능합니다.

10권의 가상 샘플은 별도 예시 목록으로 제공되며 자동으로 내 책에 저장되지 않습니다. 책등을 누르면 소개·읽기 화면이 열립니다. **이 책으로 만들어보기**를 누르면 내 비공개 책으로 복사해 편집할 수 있습니다. 이전 버전에서 만들었던 책도 같은 브라우저·사이트 주소에서 그대로 불러옵니다.

**함께 나누기**는 보낼 책을 선택해 JSON 파일을 내보내거나 받은 책을 가져오는 기능입니다. 온라인 게시판·자동 동기화·공개 커뮤니티는 아직 제공하지 않습니다. 집 컴퓨터로 옮길 때도 JSON 내보내기/가져오기를 사용하세요.

## 첫 동화책 만들기

1. 홈의 **창작 공방**을 누르고 제목과 작가 이름을 적습니다.
2. **가상 샘플 넣기**를 눌러 실제 아동 정보가 없는 숲 그림·교사 메모·아이의 말을 불러옵니다. 또는 직접 그림을 첨부하고 기록을 입력합니다.
3. 4~6페이지를 선택해 **이야기 초안 만들기**를 누릅니다. 현재는 고정 예시 문장에 교사 메모를 넣는 **모의 AI**이며 실제 모델 호출이나 비용은 없습니다.
4. 초안을 읽고 **검토했어요 · 책에 반영**을 누릅니다. 이때 기존 페이지 글·배치가 교체됩니다. 원본 자료 보관함은 유지됩니다.
5. 페이지별 글·그림을 수정합니다. `＋`로 페이지를 추가하고 앞으로·뒤로 버튼으로 순서를 바꿉니다. 원본 보관함에서 같은 그림을 다른 페이지에도 배치할 수 있습니다.
6. **책 읽기**로 넘겨 읽습니다. 동영상은 재생 버튼을 누릅니다. 방향키로 페이지를 넘기고 Esc로 닫을 수 있습니다.
7. **PDF 저장**을 누르고 브라우저 인쇄 창에서 **PDF로 저장**을 선택합니다. 권장 설정은 A5 가로, 머리글·바닥글 끄기입니다. 한글과 그림을 포함해 저장됩니다. 동영상은 파일명·안내 문구로 대체됩니다. 긴 글은 여러 인쇄 페이지로 이어질 수 있습니다.
8. **내보내기**로 미디어·원본·글이 포함된 JSON 백업 파일을 보관합니다. **책 가져오기**로 같은 앱에서 다시 편집할 수 있습니다.
9. 작업 상태를 **완성 · 교사 확인**으로 바꿔 책장에 표시할 수 있습니다. 모든 책은 비공개입니다.

## 원본과 아이의 말

업로드한 원본 파일은 변형하지 않고 데이터 URL로 보관합니다. 페이지의 그림을 바꾸거나 첨부를 삭제해도 원본 보관함에는 남습니다. **원본 저장**으로 파일을 내려받을 수 있습니다. 원본 보관함 삭제는 기존 페이지 복사본을 지우지 않습니다. 앱에서 관련 자료 전체를 지우려면 책을 삭제하세요. 이미 내려받은 백업 파일은 별도로 삭제해야 합니다.

아이의 실제 말은 교사가 입력한 별도 인용문으로 표시하고, 모의 AI 초안과 교사 편집 글의 출처를 구분합니다. AI 검토 대화상자에서 승인하기 전에는 기존 페이지가 바뀌지 않습니다.

## 저장·개인정보·제한

- IndexedDB에 현재 브라우저별로 자동 저장합니다. 서버에 자료를 올리거나 외부 AI로 전송하지 않습니다. 브라우저 저장 완료·실패 상태를 화면에 표시합니다.
- 다른 기기와 자동 동기화되지 않습니다. 브라우저 데이터 삭제, 비공개 모드 종료, 저장 공간 부족에 대비해 반드시 파일로 내보내세요.
- 로그인·접근권한·서버 암호화는 아직 없습니다. 브라우저 프로필을 공유하면 자료에 접근할 수 있습니다. 초기 개발에서는 가상 샘플만 사용하세요.
- 식별 가능한 아동 사진·영상은 해당 여부와 보호자 동의 확인을 표시해야 첨부할 수 있습니다. 이 체크박스는 법적 동의 이력 관리 시스템이 아닙니다.
- 이미지: PNG/JPEG/WebP/GIF. 영상: MP4/WebM/OGG. 파일당 최대 20MB, 책당 최대 100페이지·원본 100개입니다. 재생 코덱은 브라우저 지원에 따릅니다.
- 가져오기는 JSON 최대 100MB입니다. 원본과 페이지 배치가 함께 포함되어 백업이 커질 수 있으므로 작은 책 단위로 나누어 작업하세요.
- PDF는 브라우저 인쇄 기능을 사용합니다. Chromium과 설치된 Noto CJK 글꼴에서 한글 텍스트 추출까지 확인했습니다. 운영체제에 한글 글꼴이 없으면 Noto Sans CJK KR 등을 설치하세요.

## 환경 변수

실제 API 키, 계정, 외부 데이터베이스가 필요하지 않습니다. `.env.example`은 참고용이며 `.env`를 자동으로 읽지는 않습니다.

| 변수 | 기본값 | 용도 |
| --- | --- | --- |
| `PORT` | `3000` | 개발 서버 포트 |
| `BROWSER_EXECUTABLE` | 자동 선택 | 브라우저 테스트용 Chromium 실행 파일 경로 |

포트를 바꾸려면 macOS/Linux에서 `PORT=3001 npm start`, PowerShell에서는 `$env:PORT=3001; npm start`를 사용합니다. 비밀키를 저장소에 커밋하지 마세요.

## 테스트

```sh
npm test
npm run test:browser
```

모델 테스트 9개와 Chromium 브라우저 테스트 9개가 있습니다. 시스템에 `/usr/bin/chromium`이 있으면 사용합니다. 다른 환경은 다음 중 하나로 준비하세요.

```sh
# Playwright에서 지원하는 Chromium 설치
npx playwright install chromium
# 또는 기존 Chromium 지정 (macOS/Linux 예시)
BROWSER_EXECUTABLE=/path/to/chromium npm run test:browser
```

Linux에서 필요한 시스템 라이브러리가 없으면 Playwright 공식 설치 안내에 따라 준비합니다. 브라우저 테스트는 자체 서버와 임시 브라우저 프로필을 만들고 종료하므로 실행 중인 개발 서버를 건드리지 않습니다. 테스트별 서버 포트도 자동 선택합니다.

검증 범위: 책장 검색/분류/정렬, 샘플 읽기/복사, 이전 저장 데이터 호환성, 모의 초안 승인/취소, 원본 바이트 보존, 실제 발화 구분, 페이지 편집·재배치, 자동 저장 후 새로고침, JSON 내보내기·가져오기, 삭제, 식별 자료 동의 차단, 영상 재생, 모바일 레이아웃, PDF 인쇄용 문서, 비공개 파일 경로 차단. 한글 PDF는 설치된 Noto CJK 글꼴 환경에서 텍스트 추출까지 확인했습니다. GitHub Pages와 같은 `/book/` 경로의 정적 호스팅도 브라우저 테스트로 검증합니다.

## 기술 선택

Next.js + TypeScript + Tailwind는 이후 서비스화의 대안입니다. 현재는 **표준 JavaScript 모듈 + CSS + Node 정적 서버 + IndexedDB**로 구현했습니다. 한 명의 교사가 서버 계정·키 없이 실험하는 범위에서는 빌드 과정과 외부 런타임 의존성을 줄이고 설치를 단순하게 만들 수 있기 때문입니다. 브라우저 테스트만 Playwright를 사용합니다. 실제 로그인·권한·AI 서버 API를 추가할 때 Next.js/TypeScript 전환을 검토합니다.

- `src/app.js`: 화면 전환·편집·미리보기
- `src/library.js`: 입체 책장·검색/분류·책 소개·가상 샘플
- `src/workflow.js`: 소재·모의 AI 검토·원본 보관·PDF 인쇄
- `src/model.js`: 책 모델·가져오기 검증·미연결 AI 인터페이스
- `src/storage.js`: IndexedDB 저장
- `samples/imagination.svg`: 직접 작성한 가상 샘플 (실제 아동 그림/사진 아님)
- `server.js`: 허용한 앱 파일만 제공하는 개발용 정적 서버
